Project Overview

This Computer Organization project turns the instruction execution cycle into an interactive web experience. It models how selected RISC instructions move through the IF, ID, EX, MEM, and WB stages.

</>

Technologies Used

  • Backend: Python and Flask
  • Frontend: JavaScript, HTML, and CSS
  • Architecture: Single-cycle RISC instruction model
⭐

Key Features

  • Simulates ADD, SUB, AND, OR, SLT, and BEQ instructions.
  • Generates 32-bit machine code for supported instructions.
  • Reports CPI, IPC, throughput, and stall cycles.
  • Provides validation and diagnostic feedback.
💡

What I Learned

  • Translating processor architecture into interactive software.
  • Representing instruction stages as a clear user flow.
  • Using measurable feedback to explain performance.
  • Designing validation for technical input.

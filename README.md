## ✨ Features

- 🎨 **Warm Editorial Gold & Dark Slate Theme**: Unified aesthetic with responsive layout across all pages.
- 🌙 **Persistent Light / Dark Mode Toggle**: Saves visitor preference in `localStorage`.
- 🔍 **Interactive Project Filtering**: Instant category filtering (*All*, *Web Apps*, *Python & Flask*, *Productivity*, *Systems*).
- 📄 **In-Browser Resume Preview Modal**: Read or download `CV-1.pdf` directly inside the website.
- ✉️ **Direct Email Contact Form**: Integrated with Web3Forms API for real-time contact delivery to `devikavp14@email.com`.
- 🏆 **Certifications & Achievements**: Highlighting **National Entrepreneurship Challenge (NEC 2025 - All India Rank 8, IIT Bombay)** and **NPTEL Certification**.
- 🔝 **Scroll Progress & Floating Back to Top**: Smooth navigation enhancements.

## 🚀 Local Development Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/devika-vp/portfolios.git
   cd portfolios
   ```

2. **Run a Local Web Server:**
   ```bash
   python -m http.server 8000 --directory html
   ```

3. Open `http://localhost:8000` in your web browser.
